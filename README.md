# Mobile-Arkham-Route-Tracker
Tool to help learn 100% routes for Arkham Games

This tool needs to be used with a modified version of Arkham Route Tracker on PC made by ShikenNuggets in the release files

Official PC app project: https://github.com/ShikenNuggets/ArkhamRouteTracker
